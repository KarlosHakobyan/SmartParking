# 🅿️ SmartParking

A C#/.NET application developed as part of a Smart Parking project.

The repository contains a Visual Studio solution with separate projects for login functionality and application setup.

## 📌 Project Overview

SmartParking is organized into independent modules to keep the application structure maintainable and support further development.

The solution currently includes:

- **Login_Project** – Login-related application module.
- **SP_Setup** – Separate setup project/module.
- **Login_Project.sln** – Visual Studio solution containing the projects.

## 🏗️ Project Structure

```text
SmartParking/
│
├── Login_Project/
│   └── Login application
│
├── SP_Setup/
│   └── Setup module
│
├── Login_Project.sln
│
└── README.md
```

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/KarlosHakobyan/SmartParking.git
```

### 2. Open the Solution

Navigate to the project directory:

```bash
cd SmartParking
```

Open the solution file:

```text
Login_Project.sln
```

You can open it using Microsoft Visual Studio.

### 3. Restore Dependencies

In Visual Studio:

1. Open the solution.
2. Restore NuGet packages if required.
3. Build the solution.
4. Select the appropriate startup project.
5. Run the application.
